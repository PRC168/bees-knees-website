Robot & Engineering

Our strategy and engineering approach for the 2026–27 FIRST Tech Challenge season, BIOBUZZ.

Season strategy

Our design is built around the intake.

Every point we score depends on how quickly and reliably we can collect game elements. A robot that can control game elements consistently has more opportunities to score in the hive in every match, in both the autonomous and driver-controlled periods. That makes the intake our highest-priority subsystem this season.

In practice, this means we prototype and test intake concepts first, and design the drivetrain and scoring mechanism to support the intake rather than the other way around. We evaluate each design against clear criteria (speed, reliability, and tolerance for imperfect driving) and record the results in our build log.

Engineering tools

The software we use to design, program, and control our robot.

CAD

Onshape

A browser-based CAD platform we use to design parts and assemblies, check fit and clearances, and collaborate on the same model in real time.

Programming

Java & the FTC SDK

Our robot code is written in Java using the official FTC SDK, which provides the framework for controlling motors, servos, and sensors.

Autonomous

Road Runner

A motion-planning library we use to generate and follow smooth, accurate paths during the autonomous period.
